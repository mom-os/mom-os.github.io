# Mom.OS UTM links for launch posts

Append these to the site URL so `scripts/stats.sh` can attribute visitors.
`utm_source` is stored (no PII) on analytics events for that browser.

| Where you post | Link |
|----------------|------|
| Facebook Page | https://mom-os.github.io/?utm_source=fb_page |
| Facebook Group | https://mom-os.github.io/?utm_source=fb_group |
| Boudoir / photography audience | https://mom-os.github.io/?utm_source=boudoir |
| Personal profile / friends | https://mom-os.github.io/?utm_source=personal |

Optional: add a hash route, e.g. `https://mom-os.github.io/?utm_source=fb_page#/pricing`

Analytics respects Do Not Track and never stores emails or IP addresses.
